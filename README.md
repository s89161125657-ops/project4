# Переписка в читабельном виде

Веб-приложение, которое разбирает скопированную e-mail переписку и показывает её
в две колонки: слева — оригинал, справа — перевод на русский (Google Translate).

## Возможности

- Кнопка **«Вставить из буфера обмена»** — читает текст и сразу обрабатывает его
  (можно также вставить текст вручную в поле «Исходный текст»).
- Вверху — тёмно-зелёная надпись для коллег из Haier Biomedical.
- Письма идут в том же порядке, что и во вставленном тексте.
- Каждое письмо начинается строкой: **Имя Фамилия** (e-mail), дата и время. Затем — только текст письма,
  пустые строки убираются.
- Подписи в конце писем («Best regards», имя, должность, телефон, адрес компании и т.п.)
  убираются. Это можно отключить галочкой «Убирать подписи в конце писем».
- Юридическая оговорка Haier в конце писем («The information transmitted is intended solely…»
  и её китайская версия «本邮件可能包含敏感信息…») убирается всегда.
- Имена и фамилии участников переписки (из строк From/To/Cc) не переводятся и остаются
  как в оригинале. Исключение — **Sergei Zakharov** → **Сергей Захаров**
  (список `GLOSSARY` в файле `public/translate-core.js`).
- Строки с именем отправителя в левой и правой колонках всегда на одном уровне.
- У каждого отправителя свой цвет, одинаковый во всех письмах. Цвета запоминаются в браузере,
  поэтому остаются прежними и при следующих запусках. Письма от `zsa@inpren.ru` — всегда тёмно-синие.
- Кнопка **«Копировать результат»** копирует результат с цветами — его можно вставить в письмо Outlook.
- Распознаются форматы Outlook (англ./рус.), Gmail («On … wrote:», веб-интерфейс), Apple Mail,
  Thunderbird, Foxmail/NetEase (китайские заголовки).

## Запуск локально

Нужен Node.js 18+. Внешних зависимостей нет.

```bash
npm start          # http://localhost:3000
npm test           # тесты парсера
```

## Перевод

По умолчанию перевод выполняется через бесплатный публичный сервис Google Translate:
сначала прямо из браузера пользователя, а если не получилось — через сервер приложения.

Для стабильной работы можно подключить официальный Google Cloud Translation API —
задайте переменную окружения:

```
GOOGLE_TRANSLATE_API_KEY=ваш_ключ
```

Тогда весь перевод пойдёт через сервер с этим ключом.

## Деплой

Приложение — один процесс Node.js, слушает порт из переменной `PORT` (по умолчанию 3000).
Проверка работоспособности: `GET /healthz`.

**Docker:**

```bash
docker build -t mail-thread .
docker run -p 3000:3000 mail-thread
```

**Render / Railway / Amvera / любой Node-хостинг:** build-команда не нужна,
start-команда — `npm start`.

Кнопка «Вставить из буфера обмена» работает только по HTTPS (или на localhost) —
это ограничение браузеров. Если браузер не даёт доступа к буферу, вставьте текст
в поле «Исходный текст» сочетанием Ctrl+V.
