# ИИ-почта

Веб-приложение, которое показывает e-mail переписку в читабельном виде с параллельным переводом
(Google Translate): письма на иностранных языках переводятся на русский, письма на русском — на английский.
Письма берутся из почтового ящика (IMAP), из Outlook (перетаскиванием) или из буфера обмена.

## Возможности

Сверху — название «ИИ-почта» и область «Перетащите письмо из Outlook сюда», слева внизу —
постоянное окно **«Почта»**, справа — переписка. Оформление — «шлифованная нержавейка» с оранжевыми элементами.

В окне «Почта»: вход в ящик, папки, поиск по теме и отправителю, список писем (новые сверху, время по Москве),
кнопки и настройки:

- **щелчок** по письму — письмо выделяется;
- **двойной щелчок** (или Enter) — письмо открывается целиком в отдельном окне: заголовки, текст
  (с оформлением и картинками) и все вложения, которые можно скачать;
- **«для Haier в почту»** — выделенное письмо показывается так, как при вставке из буфера обмена
  (см. режим 1 ниже). Если письмо не выделено — берётся текст из буфера обмена;
- **«Переписка в читабельном виде»** — выделенное письмо показывается так, как при перетаскивании
  из Outlook (режим 2);
- **«Копировать результат»**, галочка «Убирать подписи в конце писем», строка состояния и цвета отправителей.

Письма в ящике только читаются: отметка «прочитано» не ставится, ничего не удаляется и не перемещается.

Два режима показа переписки:

1. **Для Haier** (кнопка «для Haier в почту» или Ctrl+V в любом месте страницы) — показываются
   и переводятся **только первые два письма**. Текст без заголовка в самом верху (ваш ответ) подписывается
   «**Sergei Zakharov**, 25.09.2026 8:23» (время вставки). Вверху — тёмно-зелёная надпись для коллег
   из Haier Biomedical. Показывается **только колонка перевода** (на всю ширину).
2. **Вся переписка** (кнопка «Переписка в читабельном виде» или перетаскивание письма из Outlook
   в область сверху, файлы .msg / .eml; щелчок по области — выбор файла) — переводится **вся переписка**,
   в две колонки (оригинал и перевод), без надписи для коллег.
   Перетаскивание из классического Outlook работает в Chrome и Edge; если браузер не
   принимает письмо, сохраните его как .msg и перетащите файл.

- Письма идут в том же порядке, что и во вставленном тексте.
- Каждое письмо начинается строкой: **Имя Фамилия**, дата и время (без e-mail). Время всегда
  пересчитано на **московское** (пекинское — минус 5 часов) с пометкой «(время по Москве)»,
  в английском тексте — «(Moscow time)». Затем — только текст письма,
  пустые строки убираются.
- Подписи в конце писем («Best regards», имя, должность, телефон, адрес компании и т.п.)
  убираются. Это можно отключить галочкой «Убирать подписи в конце писем».
- Юридическая оговорка Haier в конце писем («The information transmitted is intended solely…»
  и её китайская версия «本邮件可能包含敏感信息…») убирается всегда.
- Фраза «Напоминаем, каждый клиент нашей компании имеет личный кабинет с технической
  и сервисной документацией на нашем сайте www.awt.ru» в изложение не включается.
- При переводе на русский имена и фамилии участников переписки (из строк From/To/Cc)
  не переводятся и остаются как в оригинале. Исключение — **Sergei Zakharov** → **Сергей Захаров**
  (список `GLOSSARY` в файле `public/translate-core.js`).
- Строки с именем отправителя в левой и правой колонках всегда на одном уровне.
- Между письмами — отдельная строка «Time between messages: 2 days 3 hours 15 minutes /
  Между письмами прошло: 2 дня 3 часа 15 минут» (нулевые части не пишутся: «25 минут», «1 день 5 минут»).
  Если в этот промежуток попадает ночь (23:00–7:00 по времени того, кто отвечал), добавляется
  «(including night)» / «(включая ночь)». Для коллег Haier и адресов в Китае ночь считается
  по пекинскому времени, для остальных — по времени компьютера. Даты в китайском формате
  (2026年9月24日 17:30) считаются пекинским временем (UTC+8), остальные — временем компьютера.
- Картинки остаются в тексте на своих местах. Если письмо перетащено из Outlook (.msg / .eml),
  показываются сами картинки: их места берутся из HTML-версии письма (в .msg она хранится
  внутри сжатого RTF — приложение его распаковывает); при вставке текста из буфера — метка «[Изображение: image001.png]»
  (в текстовом буфере обмена самих картинок нет). Логотипы в подписях убираются вместе с подписью.
- Картинки, приложенные к письму вложением (не стоящие в самом тексте), показываются после
  текста этого письма под жирным заголовком **«Вложение в письмо:»** (в английском тексте —
  «Attachment to the email:»). Работает при перетаскивании письма из Outlook (.msg / .eml).
- Слово **board** переводится как **плата** (во всех падежах).
- У каждого отправителя свой цвет (текст и полоса слева; фон под текстом белый; красный не используется), одинаковый
  во всех письмах. Цвета запоминаются в браузере. Письма от `zsa@inpren.ru` — всегда тёмно-синие,
  письма **Cui** — всегда оранжевые.
- Кнопка **«Копировать результат»** копирует результат с цветами — его можно вставить в письмо Outlook.
- Распознаются форматы Outlook (англ./рус.), Gmail («On … wrote:», веб-интерфейс), Apple Mail,
  Thunderbird, Foxmail/NetEase (китайские заголовки).

## Запуск локально

Нужен Node.js 18+. Внешних зависимостей нет.

```bash
npm start          # http://localhost:3000
npm test           # тесты (парсер, IMAP — с имитатором почтового сервера)
```

## Перевод

По умолчанию перевод выполняется через бесплатный публичный сервис Google Translate:
сначала прямо из браузера пользователя, а если не получилось — через сервер приложения.

Для стабильной работы можно подключить официальный Google Cloud Translation API —
задайте переменную окружения:

```
GOOGLE_TRANSLATE_API_KEY=ваш_ключ
```

Тогда весь перевод пойдёт через сервер с этим ключом.

## Почта (IMAP)

Почтовый сервер задаётся переменными окружения (по умолчанию — почта Beget):

```
IMAP_HOST=imap.beget.com   # адрес IMAP-сервера
IMAP_PORT=993              # порт (IMAP через SSL/TLS)
```

Адрес почты и пароль вводятся в окне почты и передаются только почтовому серверу —
сервер приложения их не сохраняет и не записывает в журнал; в браузере запоминается
только адрес почты, пароль живёт до перезагрузки страницы. Приложение подключается
только к серверу из `IMAP_HOST`. После 10 неудачных входов с одного адреса за 10 минут
вход временно блокируется.

Хостинг должен разрешать исходящие соединения на `IMAP_HOST:IMAP_PORT`, а само
приложение должно открываться по **HTTPS** — иначе пароль пойдёт по сети открытым текстом.

## Деплой

Приложение — один процесс Node.js, слушает порт из переменной `PORT` (по умолчанию 3000).
Проверка работоспособности: `GET /healthz`.

**Docker:**

```bash
docker build -t mail-thread .
docker run -p 3000:3000 mail-thread
```

**Render / Railway / Amvera / любой Node-хостинг:** build-команда не нужна,
start-команда — `npm start`.

Чтение буфера обмена кнопкой «для Haier в почту» работает только по HTTPS (или на localhost) —
это ограничение браузеров. Если браузер не даёт доступа к буферу, нажмите Ctrl+V
в любом месте страницы.
